# ZEEKR Phone

Android-клиент для аккаунта и QR-привязки Zeekr X. В разделе «Мой аккаунт» можно зарегистрироваться по логину и паролю, изменить имя и фото и удалить свой аккаунт. Раздел «Мои автомобили» позволяет привязать или отвязать автомобиль. Кнопки управления передают команды серверу. Выполнение команд проверялось на эмуляторе.

## Установка и обновления

Откройте [последний выпуск](https://github.com/L3N1D/zeekr-phone/releases/latest) на Android, скачайте `Zeekr-Phone.apk` и откройте файл. Для обновления установите его поверх предыдущего выпуска с той же подписью. Данные приложения при таком обновлении сохраняются.

При открытии приложения оно проверяет номер последней сборки. Если доступно обновление, нажмите «Скачать». После загрузки клиент сверит SHA-256 и предложит открыть системный установщик. При первом обновлении Android может запросить разрешение на установку приложений из этого источника. После выдачи разрешения вернитесь в приложение и подтвердите установку.

## Исходный код

В `src/com/lenid/accountlab` опубликован код нашего клиентского модуля. `PhoneActivity` реализует экраны аккаунта и привязки, `LabHttp` обращается к серверу, `AccountGate` связывает эти экраны с интерфейсом телефона, а `ReleaseUpdate` проверяет выпуски. `LoginTest` относится к ранней лабораторной проверке входа на эмуляторе.

Для интеграции модуля нужен базовый APK телефона, точки вызова в приложении и ресурс `assets/service.json` с HTTPS-адресом сервиса. В релизе опубликована интегрированная сборка. Это независимый проект для Zeekr X.

## Формат выпуска

Имя тега имеет вид `build-<versionCode>`. У выпуска два файла, `Zeekr-Phone.apk` и `phone-update.json`. Манифест задаёт целочисленный `build`, размер APK в байтах (`size`) и SHA-256 (`sha256`). При публикации следующей версии увеличьте Android versionCode, подпишите APK тем же ключом и отметьте готовый выпуск как Latest.

## Климат

Выбор температуры и времени, быстрый обогрев и охлаждение, вентиляция и обогрев стёкол используют диалоги штатного экрана. При включённом климате через две секунды после изменения температуры появляется подтверждение. Новый выбор перезапускает таймер. После подтверждения сервер сохраняет выбранные параметры. Набор функций сидений, руля и качества воздуха зависит от комплектации.

Для интеграции со штатными обработчиками этой версии запустите `tools/attach_climate.py` из каталога проекта с декодированным деревом `apk/smali_classes7` и пересоберите этот DEX вместе с клиентским модулем. Для приёма команд с параметрами нужен сервер сборки 3 или новее.
